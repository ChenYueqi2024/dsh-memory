## 当前技术工作与源码入口

版本基线：dsh 0.2.0-rc.2；dsh-memory v0.4.1；dsh-commit v0.2.2。

1. 原生扩展：Cordis 依赖注入、事件订阅、工具注册、systemPrompt.section 与 storageDomain；主插件 `src/index.ts` 完成生命周期与宿主接线。
2. 抽取：`src/extractor.ts` 通过宿主模型路由请求结构化 new/reinforce/supersede；`src/parse.ts` 解析、归一编号并处理异常结构。
3. 存储治理：`src/store.ts` 实现工作区范围、去重、衰减、排序、批准和删除；schema v5 兼容读取 v1–v4。
4. 可靠性：主路径采用可等待的 agent/turn-stopping；成功后推进增量游标；先写新事实再退役旧事实；待审批替代项整批获准；补齐 prepare 与真实运行时 peer。
5. 配套工具：dsh-commit 从 git 暂存区读取差异，生成中文约定式提交信息；工具本身不执行 git commit。
6. 评测：20 个固定合成对照案例、4 个独立治理案例，各重复 3 次。无插件/冻结静态说明/记忆插件为 15/60、51/60、60/60；主实验插件 token 用量为静态组 5.73 倍。限于该实验，未验证一般真实代码任务收益。
