# dsh-memory 期末工程介绍视频脚本 · 评测版

主成片为真实 API 记录重放，配原创非官方鲸鱼讲解员、本机中文合成配音和逐句字幕。现场录屏另作证据片段，明确标注录制方式。不得把重放界面称为现场终端，也不得把示例输出预先写死后伪装成模型调用。

## 1. 开场与问题

画面：暗色封面、蓝色鲸鱼讲解员，紫绿强调色。片头注明厦门大学《学科实践三》、单人组、AI 协同开发。

口播：项目约定变化以后，新会话还能知道最新决定吗？dsh-memory 给 DeepSeek Harness 增加跨会话项目记忆。静态 AGENTS.md 可以准确传递知识，冻结以后则需要维护；本项目用实验测量自动维护的收益与额外成本。

## 2. 真实记录节选

画面：2026-11-14 小试验的历史输入、抽取记录与新上下文回答，注明“真实 API 记录重放”。

历史输入规定包管理器使用 pnpm，安装、更新和 CI 均遵守。实际抽取为一条 convention，按工作区写入 schema v5 存储。学习后销毁上下文，再从磁盘启动；新问题仅问包管理器，实际回答为 `{"answer":"pnpm","sources":["#fe61379f"]}`。

口播：静态文件也答对，无插件回答 UNKNOWN。这个小试验验证调用链，不作为整体效果统计。若插入新录屏，使用录屏本身的真实编号与文本，不能套用此处旧编号。

## 3. 架构与工程验证

事件流积累历史，轮末触发辅助 LLM；官方存储域按工作区隔离，动态提示词在新上下文中注入相关记忆。四个工具：memory_list / memory_forget / memory_extract / memory_approve。

半衰期：fact 14 天、decision / convention 30 天、preference 45 天。半衰期表示减半，不是到期立即删除。新事实先写入，待审批替代项整批获准后旧事实才退役。审批工具可由模型调用，不是独立人类身份认证。

插件回归测试 45 + 7，评测器另有 19 项离线自检。两个包的 prepare、干净 Git 安装和真实宿主加载已验收；对应版本 v0.4.1 / v0.2.2，远端 CI 记录见 GitHub Actions。

## 4. 三组真实评测

画面：可读的三组对照表，并始终展示“20 个固定合成主案例，每组重复 3 次”。

| 组别 | 答对 / 计划 | 准确率 |
|---|---:|---:|
| 无插件 | 15/60 | 25% |
| 冻结静态 AGENTS.md | 51/60 | 85% |
| dsh-memory | 60/60 | 100% |

插件多答对的 9 次全部来自约定变化：npm 改 pnpm、Node 18 改 22、周三发布改周五。恢复旧发布规则时静态组也答对。独立审批/删除诊断 12/12，不混入主分数。无插件的 UNKNOWN 是缺信息拒答，不能说成幻觉。

## 5. 成本与限制

主实验 tokens：无插件 9,237、冻结静态 10,455、插件 59,949；插件约为静态组的 **5.73 倍**，包含历史阶段的 99 次抽取。所有主实验与治理诊断合计 **192 单元、306 请求、89,057 tokens**；治理诊断为独立的 9,416 tokens。

口播：未折算货币费用，未计人工维护时间。只比较冻结静态文件，未比较持续人工维护的 AGENTS.md。这是单模型、短历史、受控上下文实验，不是完整 CLI/Web/TUI 任务评测，未覆盖长会话、时间衰减或复杂攻击。实验 1 字/0 秒触发设置，也不代表默认 120 字/90 秒使用频率。60/60 不能宣传为真实项目普遍 100% 准确。

可在字幕补充：AI 对照历史审阅 96 条新增候选未发现无支持事实，未做独立人工标注。

## 6. 分工与结束

作者选择课题、确认范围、配置凭证并运行真实评测，负责最终提交与答辩。AI 承担实现、测试、结果复核及材料生成。副插件 dsh-commit 读取暂存区生成中文约定式提交信息，提交操作由宿主权限管线执行。

画面展示仓库地址与完整报告入口。结尾标注“原创非官方鲸鱼形象、本机合成语音、真实记录重放”。现场录屏若另行剪入，单独标注来源。
