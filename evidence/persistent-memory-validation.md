# v0.5.0 持久记忆验证（2026-11-14）

本报告记录 v0.5.0 的本地功能与安装验收。远端状态以 [Release](https://github.com/ChenYueqi2024/dsh-memory/releases/tag/v0.5.0) 和对应提交的 GitHub Actions 检查为准。宿主为 dsh 0.2.0-rc.2，Node 22.18.0。

## 行为

新增 `pinned?: boolean` 和 `memory_pin(id, pinned)`。缺省为普通记忆；用户明确选择的、已批准且未退役的条目免时间衰减。合并/强化保留标记，替代产生的新条目不继承。取消按原时间恢复，不重置年龄；仍受作用域、相关性和容量限制，可被更新、删除。抽取器不能自行提名持久记忆。模型可调用工具，不构成独立人类身份认证。

测试先于功能接入运行，7 项失败指向缺失的 pin 方法/工具；实现后全部通过。部分新测试验证旧行为仍成立，所以并非所有新增测试都应先失败。

本地验证目录为 `D:/dev/dsh-validation-20261114/persistent-clean/`；Git 安装来源是隔离验证快照，不是已发布 main。源码安装使用已有离线缓存；首次工作区缓存缺包，切换现有 D 盘缓存后成功。Git 克隆缓存和 junction 的初次沙箱权限失败，经执行环境授权后完成。宿主依赖由既有 dsh 安装提供，没有宣称插件脱离宿主独立运行。

## 复现

```text
npm ci
npm test
npm run test:eval
npm run build
node scripts/verify-host.mjs <隔离profile> <dsh安装目录> <全新存储目录> 5
```

末尾旧 schema 版本可选 1–5。profile 需安装当前 dsh-memory 和 dsh-commit，能够解析宿主依赖；每次换全新的存储目录。时间测试不修改操作系统时间，模型输出为固定夹具，不需要 API Key。

## 与历史实验分开

v0.4.1 的正式真实模型评测保持 **15/60、51/60、60/60，306 请求，89,057 tokens，主组 5.73 倍 token 用量**。新增验证没有真实模型 API 调用，不改旧报告、原始数据或成本。旧操作视频仍是 v0.4.1，没有 memory_pin。

这些测试证明程序执行既定规则，不能证明长期实际准确率、14/30/45 天参数最优、每次必召回，或能抵御模型误判和复杂攻击。
