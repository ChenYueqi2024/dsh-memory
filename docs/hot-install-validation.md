# v0.5.1 热安装回归验证（2026-11-14）

v0.5.0 只订阅 `agent/created`。如果 dsh 网页在插件安装前已经创建空 Agent，之后复用该会话不会重发创建事件，因此工具可用但记忆提示段未注册。上轮网页实录中的失败会话创建于安装前；此轮在真实 AgentRegistry、AgentLoop、SystemPrompt 和 JSON 后端中独立复现，不依赖模型判断。

最小修复：监听创建事件后，遍历 `ctx.agents.list()` 为已有 Agent 补挂相同提示段；按 Agent 对象去重，继续排除子 Agent、遵守工作区/审批/退役边界。插件加载完成前等待存储打开和挂接完成。卸载时清理提示段，等待进行中的抽取并关闭本插件的存储域，允许再次启用。
